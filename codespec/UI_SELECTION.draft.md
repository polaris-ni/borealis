## 2 逐面板判据

**A. 流式选区（A1 聚焦 / A2 失焦）**

- A1-a：首行选中段右界到**网格列数**，不是到最后一个有字符的列——与 `ui::row_spans` 的闭开区间同口径，故绘制层与复制层用的是同一张区间表。
- A1-b：选中格底色换成主题 selection 槽；前景走 `ui::resolve` 的最小对比度重合成（阈值 4.5，裁决 7.26①）。
- A1-c：选区层落在色带之上、字形之下，字形不被染色。
- A2-a：失焦**不改行列区间只改色**，与光标失焦降级（`SPEC.FEAT.RENDER.04`）同一条思路。
- A2-b：inactive 色由 selection 与 `default_background` 各半算出，不落第二个槽。

**B. 边界（B1 双宽 / combining / 回看）**

- B1-a：双宽字符两格同色，不出现「半个字有色、半个字没色」——与复制侧「延续格永不产第二个字符」（裁决 7.32③）同源。
- B1-b：combining 随基础码点并进同一段，不另占一格（架构 §4.1、裁决 7.23ⓑ）。
- B1-c：回看态选区随 scrollback 滚出滚回；**scrollback 饱和后新输出会让选区相对内容下移一行**，该漂移的消除属存储侧单调行号（裁决 7.32② 的显式欠项），不在本稿视觉范围。

**C. 与既有绘制层的层叠（C1 SGR / C2 光标块）**

- C1-a：选中不改变任何 SGR 笔形——下划线、删除线、粗体、暗淡照常画，选区只换底色。
- C1-b：`SGR 7` 反色格被选中时按「先反色合成、再叠选区底色」，即**选中覆盖反色结果**（否则选中态在反色行上不可见）。
- C1-c：真彩色底色格被选中时 selection 槽胜出，理由同上。
- C2-a：光标层在选区层之上；块形格仍走「画字 → 盖块 → 按该格合成底色重画」三段式（裁决 7.29），第三段取的合成底色此时就是选区色。
- C2-b：故被选中的光标格仍显块形，不被选区色吞掉。

**D. 三套主题的 selection 槽**：同一段内容在 Dracula / Nord / One-Dark 下各自检验可辨识度；判据是「与 `default_background` 拉开一档亮度，且与任一前景色的对比不达标时走 `min_contrast` 重合成」。

**E. 列模式（Alt+拖拽）**

- E1-a：与流式同色同层，只换区间形状，**不加描边**（避免与回看指示条混淆）。
- E1-b：仅形态约定；Alt 态判定等 G18 回货，回货前不落代码。

**F. copy-on-select 与右键三态**

- F-a：copy-on-select 打开时拖拽抬起即写剪贴板，画面**不加**闪烁或描边反馈（选中态本身已是反馈）。
- F-b：右键三态的「复制」项在无选区时置灰（`MenuItem.enabled = false`），不是点击后静默失败；菜单形态已在 `codespec/UI_COMMANDS.draft.svg` 评审收口，本稿不重画。
- F-c：粘贴（多行警告与逐块排期）不产生任何选区视觉，与本稿无交叉。

## 3 决策点（已拍板：全取建议项，逐条理由与代价见裁决 7.38①）

| # | 议题 | 选项 | 影响面 |
|:---|:---|:---|:---|
| **D1** | 高亮的实现形态 | ① **底色替换**：选中格的 background 换成 selection 槽，走 `ui::resolve` 后由既有**色带层**画出，前景按 `min_contrast` 重合成〔建议〕；② alpha 叠加：色带之上、字形之下 `blend_rect` 半透明层，前景不动 | ① 像素可逐位断言（与色带同一条不透明快速路径），代价是选中段的 run 会因底色不同而被切开（`layout_row` 按样式全等合并，裁决 7.23②）；② 不切 run、不改前景，代价是像素断言依赖框架 `blend_rect` 的**舍入口径**，而该口径本仓未实测（裁决 7.33⑧ 只确认源 alpha 混合可用） |
| **D2** | 选区色来源 | ① **主题表新增 `selection` 槽**（8 套各值）+ `PaletteSpec` 新增字段 + 配置键可覆盖，缺键回落主题值〔建议〕；② 由 ANSI blue + alpha 派生；③ 全局单值不随主题 | ① 与光标色（U3）同形态，色值仍单源于 `config/themes`（裁决 7.26②）；② 零新增色值但浅色主题上不可辨；③ 与主题表脱节，成为第二真值源 |
| **D3** | 失焦态 | ① **同色向底色混 50%**〔建议〕；② 只画描边不填充；③ 与聚焦完全相同 | ① 不需第二个槽位，算式一条；③ 最省事但切窗后选区在哪一眼看不出（本仓光标已采失焦降级，口径不一致） |
| **D4** | 与搜索命中 / 超链接 hover 同格 | ① **选区盖过命中高亮**〔建议〕；② 命中盖过选区 | `SPEC.FEAT.INTERACT.04` / `05` 未开工，现在定序只是把层序写进架构 §9.2，避免两棒各画一层后打架 |
| **D5** | 首行 / 末行的选中右界 | ① **截到网格列数**（行尾空白格也上底色）〔建议〕；② 只到最后一个有内容的列 | ① 与 `ui::row_spans` 一致，绘制与复制同一张表；② 是 iTerm2 形态，需要「行尾空白」判据，与 `trim_trailing_space` 的 U+0020 口径同源但会多一次扫描 |
| **D6** | 列模式视觉 | ① **与流式同色同层、只换区间**〔建议〕；② 额外描边区分 | ② 与回看指示条同形，易混 |
| **D7** | copy-on-select 反馈 | ① **无额外视觉**〔建议〕；② 短暂描边闪一下 | ② 需要定时器与一帧额外绘制，收益仅是确认感 |

## 4 与现状的差距 → 实现须达到的条目

1. `ui::PaletteSpec` 无 selection 槽，`config::themes` 八套也没有该色值——**色值的唯一来源要先补**（D2 拍板后）。
2. 「哪几格被选中」不是 `grid::Cell` 的事实，而是区间级事实：现路径 `ui::layout_row(row, spec)` 收不到它。D1 选 ① 则须给它加一个「本行选中列区间」入参（保持纯逻辑、可脱界面单测），选 ② 则绘制侧在色带层之后另发一层 `fill_rect` / `blend_rect`。
3. 架构 §9.2 的五层绘制序列要按 D1 / D4 更新层序（新增一层或改色带层的输入）。
4. `src/ui/terminal_view.cpp` 尚无 `on_pointer_event` 覆写：按下/拖动/抬起 → `ui::cell_at_point` → anchor/focus 推进的状态机未落（落点换算已落，见架构 §10.2）。
5. 剪贴板写入与 copy-on-select 未落；`Session::copy_text`（会话短临界区内取文本交回主线程）未落。

## 5 验收判据（拍板并实现后）

- **纯逻辑**：选中列区间与 `ui::row_spans` 逐行相等；D1 选 ① 时选中格的合成底色恰等于 selection 槽、且前景在低于 `min_contrast` 时被重合成（`utest_palette` / `utest_cell_layout` 各补例）。
- **像素**（`tests/integration/itest_render_viewport.cpp` 通道，`HeadlessSurface` RGBA8）：两帧差分断「未选格逐位不变、选中区间整格变为 selection 色」；失焦帧断「该色等于 selection 与 default_background 各半混合」；D1 选 ② 时须**先实测** `blend_rect` 的混合与舍入式子，否则本条降级为「有墨/无墨 + 色差方向」的弱断言并写明。
- **不做**：真机目视以外的手感（拖拽跟手、跨回看滚动）不在本稿验收面，须人工走查（会话锁屏下 `SendInput` 静默失效，同裁决 7.31 口径）。
