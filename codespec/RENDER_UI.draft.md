## 0 本稿的性质：目标，不是现状

图上的每一格都是按**目标网格**逐格落位画出来的，不是任何一次真实渲染的截图：

- 格宽 / 行高 / 基线取框架 `render::FontEngine::monospace_cell` 的**实测值**（Cascadia Code 14pt：100% → 11×22 dp、基线 18；150% → 17×34px、基线 27；200% → 22×44px、基线 36；w400 与 w700 同宽）。
- 颜色合成次序照 `ui::resolve` 的实测实现：**亮色档 → 暗淡 → 反色 → 最小对比度**，暗淡按 45% 向底色靠拢，最小对比度按 WCAG 相对亮度式子整数插值到达标。
- 框线（U+2500–U+257F）与块元素（U+2581–U+2588）在图上是**矢量线段与矩形**，用来表达「相邻格接续无断点」「上下贴格边」这两条目标；实现侧仍是把码点交给框架 shaping，判据不变。
- 逐格居中的落位方式是为了让「字形是否越出格盒」这件事与具体字体文件解耦——实现按 run 整段绘制（裁决 7.23②），等宽字体的 advance 与格宽同源，两者在正确实现下应当重合。

所以：**实现完成后须与本图逐格比对**，而不是「看起来差不多」。

## 2 逐面板判据

### A. 目标首屏（62×16，Dracula，块状闪烁光标）

一屏里同时成立才算过：提示符着色、编译输出、警告框（Rust 式 `-->` 与 `^^^` 对齐到源列）、中文测试名、光标所在行。

- **V1 列位对齐**：任意两行中同一列的字符，其格盒左边界 x 坐标差为 0。
- **V2 换行边界**：行内容到第 62 格整体换行，第 62 格之后不得残留上一行的半格字形（`SPEC.FEAT.TERM.08` 已在全链路用例锁定，上屏侧不得再引入偏移）。
- **V3 脏行只重绘变更行**：单帧内只提交变更行的色带与文本片段（`SPEC.FEAT.RENDER.01`）；由 `Painter::clip_bounds()` 自行跳过窗外行（裁决 7.23ⓐ）。
- **V4 光标格反色**：块形光标覆盖的格，其字形以「底色=光标色、前景=原底色」重画一次，三段式次序为 先画字 → 画块 → 按反色重画该格。

### B. 目标样式矩阵（SGR 全档 × 三个合成开关）

- **V5 16 色**：索引 0..7 / 8..15 两行前景与一行背景色带，色值取自主题的 `basic[16]`，可被主题整体重映射。
- **V6 256 色 / 真彩**：16..231 为 6×6×6 立方、232..255 为 24 阶灰，式子不受主题影响；真彩段直接取 SGR 38;2 的三元组。
- **V7 属性笔形**：`1` 换字重不改格宽；`2` 暗淡只折进前景（不设独立标志）；`3` 斜体；`4` 单下划线；`9` 删除线；`7` 反色按「亮色档 → 暗淡 → 反色」次序交换前后景；`8` 不可见只隐去字形与装饰、底色仍画（图中以灰底色带示意）。
- **V8 bold-is-bright**：开关只作用于**前 8 色**，索引 8..15 不受影响（对照 B 与 B2 两屏的 `red/green/blue`）。
- **V9 最小对比度**：开关打开后，`#282828 on #000000` 必须被抬到可读（阈值 4.5），关闭时保持原色（对照两屏同一行）。
- **V10 多标志叠加**：暗淡 + 反色 + 亮色档同时命中时，次序结果唯一（B2 末行），不允许出现「先反色再暗淡」的第二条路径。

### C. 目标光标（三形态 × 闪烁两相 × 失焦，九态）

- **V11 形态**：块 = 整格填充 + 格内字形反色；下划线 = 行底 1px 横条；竖线 = 格左 1px 竖条、高度为整格行高。
- **V12 off 相**：闪烁处于 off 相时该格**完全不画光标**，字形保持原色（不是画成暗色）。
- **V13 失焦降级**：块形失焦 → 1px 空心描边、静止不闪；下划线与竖线失焦 → 同形态、静止。
- **V14 双宽格光标**：光标落在双宽字符上时块宽为 2 格（本图未画，实现须按此判据）。

### D. 目标宽度与字形（淡青细线 = 真实网格）

- **V15 双宽占位**：CJK / 全角 / emoji 各占 2 格，字形居中于 2 格盒内，其后 ASCII 的列号 = 起始列 + 2×字数（图中「后接 ASCII 必须从第 9 格起」）。
- **V16 延续格不画**：双宽字符的第二格是空串，既不产文本片段也不画豆腐块（裁决 7.23②）。
- **V17 框线连续**：`─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼` 的横线在格宽方向接满、竖线在格高方向接满，相邻格之间不得留缝或压线——这也是框架量格宽时把 U+2500 计入参考字形集的原因（裁决 7.22②）。
- **V18 块元素**：`▁…█` 八档高度按 1/8 格高阶梯、上下贴格边。
- **V19 零宽并入**：combining 标记拼在基础码点之后随同一 run 送出（裁决 7.23ⓑ），基础格不推后续列。
- **V20 Ambiguous**：窄档口径下 `± £ ×` 各占 1 格；同一份输出在宽档口径下列位仍与全链路用例一致（`SPEC.FEAT.TERM.08`，裁决 7.20）。

### E. 目标回看（贴底跟随 vs 回看 15 行）

- **V21 距底恒定**：回看期间新输出照常进 scrollback，画面锚定在「距底 N 行」不动（裁决 D6①）；每帧把 `offset_y` 重投影为 `max_offset_now − back_rows`。
- **V22 两屏差 N 行**：本图 N=15，左右两屏内容恰好差 15 行，是最直观的正确性检查。
- **V23 回看中的实时输出不丢**：回看态收到新字节仍写权威网格，只是不移动画面。
- **U1**：右侧 2dp 位置指示条是否本棒画（见 §4）。

### F. 目标主题（同一内容三套配色）

- **V24 换主题不动列位**：字号、网格、光标形态与 A/D 各屏完全一致，只有色值变。
- **V25 亮色主题**：默认前景/背景随主题翻转，最小对比度与 bold-is-bright 的开关语义在亮底下同样成立。

### G. 目标 DPI（三档）

- **V26 格宽取整归框架**：dp 格宽 = 物理格宽 ÷ scale（100% 与 200% 同为 11.00，150% 为 17÷1.5=11.33），上屏层不再二次取整。
- **V27 无半像素漂移**：任何一档 DPI 下格边界都落在整数物理像素上（`SPEC.FEAT.RENDER.05` 的验收线；DPI 变更的重建与字形缓存失效属第二棒）。

## 3 与现状的差距 → 实现须达到的条目

以下差距**不是本稿的判据**，而是实现前必须先补的料；每条右侧标出处置。

| # | 差距 | 实现须达到 | 处置 |
|:---|:---|:---|:---|
| G-1 | `ui::CellPaint` 只有 `underline: bool`，状态机未解析 `SGR 21 / 4:3 / 4:4` | 双线 / 波浪线有可判定的笔形（见 U4） | 待拍板 U4 |
| G-2 | `render::Font{family,size_pt,weight}` 无斜体位，`draw_text_runs` 不收 `TextLayoutOpts` | 斜体能经批量入口送出（见 U5） | 待拍板 U5（属渲染链路缺口，按 AGENTS.md §5 第 1 条优先在 Aurora 侧补公共 API + 单测） |
| G-3 | `PaletteSpec` 无光标色字段 | 光标色来源唯一且可配（见 U3） | 待拍板 U3 |
| G-4 | 内置字体只有 Cascadia Code 常规面 | 随包附 Bold / Italic / BoldItalic 面，否则 `SGR 1` 只剩 bold-is-bright 一条线索 | 第二棒 `SPEC.FEAT.RENDER.02` 的字体范围，本棒先锁判据 |
| G-5 | 框线/块元素在 Cascadia 常规面里的覆盖未走查 | 框线必须来自等宽单格面，不得被比例 CJK 面承接（否则 V17 破） | 走查项，随本棒真机比对 |
| G-6 | CJK 缺字回退链未接 | 默认配置下含汉字的输出呈现为字形而非豆腐块，且回退后仍占 2 格（`SPEC.FEAT.RENDER.02`、裁决 7.16②） | 本棒落地回退注册（`register_font_file`），判据即 V15 |
| G-7 | `SGR 5` blink 无落点 | 闪烁由绘制侧按 500ms 方波驱动，off 相整格不画（V12） | 本棒落地 |

## 4 待拍板（结构化选项）

- **U1 回看位置指示条**：① 画（右侧 2dp，`fill_rect` 一块，回看态有视觉线索）② 不画（回看态无任何线索，靠内容判断）。
- **U2 视口内边距**：① 0 dp（贴边，同 A 图）② 四周 4 dp（更像现代终端，但首行不再贴顶，且 dp 取整要保证不破坏格边界）。
- **U3 光标色来源**：① 固定取 `default_foreground`（零配置）② `PaletteSpec` 增 `cursor_color`（可选字段，缺省回落 ①）。
- **U4 双线 / 波浪下划线是否本棒落地**：① 本棒一并做（需扩 `CellPaint` 为档位枚举 + 状态机解析 `SGR 21 / 4:3 / 4:4`）② 只做单线，双线/波浪按 `SPEC.FEAT.RENDER.03` 的原文列为延后子项。
- **U5 斜体的送出口**：① 本棒斜体走逐片段 `draw_text` + `TextLayoutOpts`（混合入口，批量收益略降）② 先在 Aurora 侧给批量入口补排版选项（按 AGENTS.md §5 第 1 条走公共 API + 单测 + 文档回写，本棒等这一腿）。
