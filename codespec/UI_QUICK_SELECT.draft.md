## 1 范围与边界

**本期交付**：

1. **一个模态 quick select 模式**：打开时扫描**当前可见窗**的全部行，按 URL → 路径 → 哈希的优先级产出互不重叠的候选，给候选起点标字母标签。
2. **一个全局命令与快捷键**：`quick_select.open`，`Ctrl+Shift+Space`；命令面板同一入口；落点为当前窗当前标签的焦点 pane。
3. **按标签复制**：候选 ≤ 9 时单字符标签（`a s d f g h j k l`），10–81 时全部双字符（`aa as ... ll`）；按到完整标签即把开模时冻结的文本写剪贴板并退模；`Backspace` 退一位，`Escape` 退模，其它键退模且不转发。
4. **标签块绘制**：候选起点起 N 格（N = 标签字符数）的实心块，selection 底 + 高对比字色；层序在链接悬停之后、发送侧提示卡与 dead-session 浮层之前。
5. **取消条件**：`Escape`；非法键；指针按下；滚轮；可见窗顶 / 行列数 / 距底行数变化；视口失焦；搜索浮层已开时不允许进入。
6. **纯逻辑可测**：`include/borealis/ui/quick_select.h` 的行扫描、文本提取、标签分配与精确查找都是无 Aurora 类型的纯 C++，可独立单测。

**本期不交付**（§9 在册）：

- 智能选择（引号/括号配对扩展，iTerm2 语义）——`SPEC.FEAT.INTERACT.02` 的另一条延后子项，仍留 M4。
- 跨行候选（折行的 URL/路径不拼接）、OSC 8 隐藏目标、邮箱/UUID/IP 等额外档位。
- 鼠标点标签（本棒只有键盘标签；鼠标按下只退模）。
- 标签自定义字母集、大小写双档、超过 81 个候选的分页。
- 真机走查（AGENTS §4.4 第 33 条）：本条只称「件本体 + 无头判据落地」，不称「可用」。

## 2 触发与模式状态机

**打开**（`TerminalView::open_quick_select()`）：

1. 搜索浮层开着即返回（F10）。
2. 从 `mirror_` 的 0..`rows()-1` 逐行调 `scan_quick_select_row(line, window_top + i)`；按阅读序拼表。
3. 调 `assign_quick_select_labels()`：超过 81 个候选只保留前 81 个（阅读序），其余不标。
4. 空表即不进入模式（没有可复制的东西，不画空标签、不改任何状态）。
5. 记下四枚快照：`window_top`、`rows`、`columns`、`back_rows`；清输入前缀；标脏。

**输入**（在 `on_key_event` 的 `dispatch_observer_` 之后、`key_pre_filter_` 之前）：

| 按键（仅 `Down`） | 行为 |
|:---|:---|
| `Escape` | 退模，消费。 |
| `Backspace` | 输入前缀非空则删末字符并重绘；空前缀则什么都不做。消费。 |
| 无修饰的 `A`–`Z` | 折成小写字符追加到前缀；若没有候选标签以它开头 → 退模；若恰好命中完整标签 → 置 `CopyRequest::QuickSelect` 并退模；否则只重绘。消费，并置 `swallow_next_text_`。 |
| 其它任何键 | 退模并消费；键位属可打印档（字母/数字/空格/标点）时同样置 `swallow_next_text_`。 |

状态机只需两句话：**前缀必须是某个标签的前缀；命中完整标签即完成**。单字符档的多字符输入不会出现——单字符档的标签都只有一位；双字符档第一击只可能是前缀，第二击才可能完整。

**文本通道**：`on_text_input` 在既有 `swallow_next_text_` 判定之后再补一条「模式仍开着就消费不写会话」，覆盖后端先发文本、或输入法绕过按键通道的形态。这样模态期不会有任何字符漏进会话。

## 3 候选识别口径

三档扫描都在**单行**内完成，不跨行拼接（D8）。每档先取「本档字符表下的极大游程」，再在游程内判起点与尾部，最后按优先级去重叠。

### 3.1 URL

- **起点**：`scheme://`（scheme 体 `[A-Za-z][A-Za-z0-9+.-]*`，起点前一字符不是字母数字）或 `www.`（前一字符不是字母数字、后一字符是字母数字）。`://` 之后至少还有一个字符；修剪后仍须有字符（`https://` 本身不算）。
- **字符表**：与 `ui::url` 同口径——ASCII 取 `-._~:/?#[]@!$&'()*+,;=%` 与字母数字；非 ASCII 默认放行，但 C1、U+00A0、通用标点、CJK 标点与全角标点区段断开。
- **尾部**：交替剥 `.,;:!?'"` 与不配对的右括号，直到稳定（`https://a/x).` → `https://a/x`）。
- **不查白名单**：`ftp://`、`git://` 与任意自造 scheme 都标；quick select 只复制，不打开（D2）。
- **OSC 8 不参与**：复制的是屏上文字，不是链接表里的隐藏目标（D8）。

### 3.2 路径

- **路径字符表**：字母数字与 `-._~:/\@+%$`；非 ASCII 按 URL 的断开区段处理（CJK 文件名可整段进候选，CJK 标点断开）。空格、引号、括号、`<>|,;=!?*&#^` 与反引号一律断开。
- **显式起点**（起点前一字符不是字母数字/`_`/`-`/`.`/`~`）：
  - `/...`（根路径；至少一个非分隔字符）；
  - `./...`、`../...`；
  - `~/...` 与 `~user/...`；
  - `X:\...`、`X:/...`（盘符起点，允许 `C:\` 这样的根）；
  - `\\server\share`（UNC）。
- **裸相对路径**：只在游程起点、且**至少两个 `/`** 时接受（`src/ui/url.cpp` 标、`and/or` 与 `TCP/IP` 不标）；全由数字与分隔符组成的串不标（`2026/10/22` 不标）。
- **尾部**：剥尾部的 `.` 与 `:`；目录尾的 `/` 保留（`/usr/bin/` 原样复制）。
- **含 `://` 的游程跳过**：那一整段已归 URL 档；URL 未成立（如缺 host）时也不降级切成子路径。

### 3.3 哈希

- 连续十六进制段，长度 **7–64**；至少含一个 `a`–`f`（大小写均可），故纯十进制数不标。
- 前后边界不得是字母数字、`_` 或 `-`（`foo-abc1234` 不标；`abc1234` 单独成词才标）。
- 长度超出 64 的极大游程整段不标（不截 64 位前缀）。

### 3.4 优先级与重叠

1. 先收 URL，再收路径，最后收哈希。
2. 后一档的区间与已收区间**有任何交叠即丢弃**（URL 里的 `/path` 不会再标一枚路径，路径里的 40 位 hex 不会再标一枚哈希）。
3. 最终按 `(存储行, 起始列)` 升序排；标签按这个阅读序分配。

## 4 标签分配

- 字母集固定 `asdfghjkl`（9 个，WezTerm 缺省），上限 `9 × 9 = 81`。
- 候选数 `N ≤ 9`：单字符 `a`、`s`、…、`l`。
- `10 ≤ N ≤ 81`：**全部**双字符，按首位分组、次位枚举：`aa`、`as`、…、`al`、`sa`、…、`ll`。
- `N > 81`：按阅读序取前 81 个，其余不进入模式表（不画、不可按）。
- 标签字符只用 ASCII 小写；输入侧无修饰字母键折成小写，`Shift+A` 不算 `a`（D3）。

## 5 视觉与层序

**几何**：标签块从候选的起始列开始，宽 = `标签字符数 × cell_width`，高 = `cell_height`，与那一行同顶；不圆角、不描边、不外扩。块可能盖住候选的前 1–2 个字符，这是有意的——标签必须落在候选起点，用户才知道它指哪一段。

**用色**：底 = `selection_ink()`（持焦取 selection 槽、失焦按同色与默认底各半混合）；字 = `enforce_contrast(default_foreground, 底, 4.5)`。不新增主题槽，不写死十六进制色（与 `UI_SELECTION.draft.md` 同源）。

**字体**：沿用 `ref_font_` 的族与字号，字重 600；标签整串一次 `draw_text`，不逐字符落笔。

**层序**（`on_paint` 自下而上）：

```
① 默认底色
② 每行正文与色带（含选区/搜索命中）
③ 光标、回看指示条、命令块分隔线
④ 链接悬停线 + 提示条
⑤ quick select 标签块        ← 本棒新增
⑥ 发送侧一次性提示卡
⑦ dead-session 浮层
⑧ 广播角标
```

标签块压在正文与链接悬停之上（否则被下划线穿过读不清），让位于两张状态卡（那两条是更重的状态）。纯展示，不写命中盒、不吃指针。

**示意**（标签块用 `[x]` 表示，实际是实心色块）：

```
$ git clone https://github.com/foo/bar.git
            [a]────────────────────────────
$ ls ./build/src/ui/url.cpp
     [s]────────────────────
$ git log --oneline
[a]bc1234  fix: ...
```

同屏多候选时按阅读序 `a s d …`；10 个以上时块宽变成两格（`aa`、`as`……）。

## 6 复制与取消

**复制**：候选在扫描时已冻结 `text`（双宽/组合符号按 `ui::copy_text` 的口径提取）。命中完整标签时只做三件事：把 `text` 存进待复制槽、置 `CopyRequest::QuickSelect`、退模。下一帧 `flush_copy_request()` 走既有 `Presentation::clipboard_write`（缺省 `ClipboardOutbox::write`），动作与选区复制同一条路径。文本为空（理论上不会出现）即不写。

**取消**（任一条成立即退模并清候选/前缀/标签盒）：

| 触发 | 是否吃掉这一击 | 理由 |
|:---|:---|:---|
| `Escape` | 是 | 模态的标准出口。 |
| 非法标签键 | 是 | 模式期的键不该漏进会话。 |
| 指针按下 | 是 | 点一下只退出，不在标签底下顺带起选区/开链接。 |
| 滚轮 | 否 | 用户要看别处；滚动照常发生，模式退出。 |
| 可见窗顶 / 行数 / 列数 / 距底行数变化 | — | 标签坐标已不再对应同一段文字；在 `on_frame` 副本并入后比较快照。 |
| 视口失焦 | — | 键已经不会进本视口，标签没有意义。 |
| 输出只改写同一行、未推窗 | 不取消 | 行号与列号未变；复制的是开模时冻结的文本，不读改写后的格子。这是有意的取舍：不因一次状态栏刷新就把整模打掉。 |

| **D1** | 触发通道与键位 | 全局命令 `quick_select.open` + `Ctrl+Shift+Space` | 命令表同时喂快捷键与命令面板（与 `search.open` 同源）；不新增工作区保留键。代价：`Ctrl+Shift+Space` 在部分输入法里是候选窗切换键，真机可能被吞——本通道无法验证 IME，登记为未走查项。 |
| **D2** | 候选档位与 URL 白名单 | URL / 路径 / 哈希三档；URL 不查 `terminal.link_schemes` | 需求点名三档；quick select 只复制不打开，白名单是「打开」的安全闸，套到复制上会让 `ftp://` 一类明明看得见的串不能取。代价：会标出不可点的 URL（与 INTERACT.05 的可见差异，属语义分叉而非缺陷）。 |
| **D3** | 标签字母集与多字符规则 | `asdfghjkl`；≤9 单字符，10–81 全双字符，>81 截断 | WezTerm 缺省字母集，避免 `Ctrl+C` 一类与终端控制键混淆；全双字符让状态机只有「前缀/完整」两态，不出现「有的单字符、有的双字符」的歧义。代价：10 个候选时每个标签都占两格，窄 pane 上更挤。 |
| **D4** | 标签视觉 | 候选起点起 N 格的实心 selection 块 + 高对比字 | 不新增主题槽（沿用选区色）；不圆角/不描边，逐格几何可像素断言。代价：会盖住候选开头的 1–2 个字符。 |
| **D5** | 模态取消条件 | Esc / 非法键 / 指针按下 / 滚轮 / 行窗变化 / 失焦 | 覆盖「坐标失效」与「用户改主意」两类；输出不推窗时保留，避免状态栏刷新即打掉整模。代价：持续输出且推窗的程序里模式很短命——这与「视区内」的需求一致。 |
| **D6** | 复制通道 | 开模冻结文本 + `CopyRequest::QuickSelect` + 帧边界写剪贴板 | 复用既有唯一剪贴板接缝；按键回调不做 IO（AGENTS §4.5 第 25 条）；即使按下标签时那一行已被改写，复制的仍是标签所指的那段。代价：开模后到按键前的改写不会被反映（有意的 snapshot 语义）。 |
| **D7** | 触发落点与面板共存 | 当前窗当前标签的**焦点 pane**；搜索浮层开着时不进；失焦即退 | 与 `search.open` 的「按窗解析」同源，但取焦点 pane 而不是 1 号格（搜索那一处取 1 号是既有欠账，本棒不扩散）。代价：从命令面板触发时若视口尚未收回焦点，模式会在下一帧自退——登记为已知形态。 |
| **D8** | 显式边界 | 单行、可见窗、81 枚上限、不碰智能选择、不做 OSC 8、不做鼠标标签 | 把「折行 URL 不拼接」「隐藏目标不复制」「候选过多只取前 81」写成可断言的边界，而不是留给实现偶然。代价：长 URL 折行时只能取到其中一段。 |

## 8 验收判据

**纯逻辑（`utest_quick_select`）**：

1. URL：`https://` / `ftp://` / `www.` 三档；尾部 `).` 修剪；`https://` 缺 host 不标；`1://example.com/x` 不标（scheme 首字符须为字母）；`x-custom+v1.2://host/x` **照标**（任意自造 scheme，D2 的「不查白名单」是有意的）。
2. 路径：`/usr/bin`、`./build`、`../x`、`~/notes`、`~user/x`、`C:\temp\x`、`C:/temp`、`\\server\share`、`src/ui/url.cpp` 标；`and/or`、`TCP/IP`、`2026/10/22`、裸 `/` 不标。
3. 哈希：7/40/64 位标；6 位、65 位、纯数字、`foo-abc1234` 不标；大写可标。
4. 重叠：`https://a/b/c` 只出一条 URL；`/tmp/abc1234` 只出一条路径。
5. 文本：双宽与组合标记的提取与 `ui::copy_text` 同口径。
6. 标签：3 枚 → `a,s,d`；10 枚 → `aa,as,...`；90 枚 → 候选表截到 81 枚（首 `aa`、末 `ll`）；自定义 `limit` 与自定义字母集容量同样截断；空字母集只清标签不删候选。

**界面（`itest_quick_select`）**：

1. 投喂含三档候选的行，开模后 `quick_select_active()` 为真、候选的 `kind/text/label` 与预期逐字相等。
2. 标签盒与候选起点同格、宽 = 标签字符数 × 格宽；像素在盒内取到 selection 底，盒外那一格是默认底。
3. 按完整标签键：模式退出、下一帧剪贴板替身收到冻结文本、会话 `written` 不增（键未漏进会话）；同一次物理键的文本事件也被吞掉。
4. `Escape` / 非法键 / 指针按下 / 滚轮 / 输出推窗 / 失焦各退模；滚轮那条同时断言回看位置变化。
5. `Backspace` 在双字符档退一位后仍可完成；空前缀时不退模。
6. 无候选时开模为 no-op（`quick_select_active()` 仍假）。

**变异自证**：至少四支——删 URL 的尾部修剪、删路径的裸相对「两斜杠」闸、删候选上限截断、删按键后的 `swallow_next_text_`；每支须有指名红案。

## 9 显式边界与「不称可用」

- **可见窗**：只扫 `ScreenMirror` 当前副本；回看偏移变了要重新开模。不扫 scrollback 全量，也不跨 pane。
- **单行**：折行的 URL/路径/哈希按两段分别判；不拼接、不继承上一行的 scheme。
- **OSC 8**：只复制屏上文字；链接表里的隐藏目标不参与（与 INTERACT.05 的 `find_link_at` 语义分叉，见 D2）。
- **输入法**：`Ctrl+Shift+Space` 可能被 IME 占用；preedit/候选窗不归本棒（`SPEC.FEAT.INTERACT.06`）。真机未走查。
- **Win32/MSVC**：未编译验证；本棒的键位折小写只依赖 `KeyCode::A..Z` 的连续段，与后端无关，但仍按「推断」记。
- **不称可用**：AGENTS §4.4 第 33 条——真机键位与手感未走查；`src/main.cpp` 不编入 runner，命令落点那一跳无自动化证人。

**实落清单（2026-10-23，裁决 7.135）**：

- **范围**：D1–D8 全部按稿落地；智能选择、跨行候选、OSC 8 目标、鼠标点标签、字母集自定义与分页均未交付（同 §1 的「本期不交付」）。
- **候选坐标**：`span.row` 是存储行序，绘制按 `window_top` 现折屏幕行。可见窗比标称网格矮时，顶部空白行会进历史（`Storage::set_rows` 的底部锚定），故测试里的存储行是「窗顶 + 屏幕行」而不是屏幕行本身——`itest_quick_select` 第 1 案按 `24 − 可见行数` 算窗顶并把这条写成断言，实现若误存屏幕行即红。
- **观测盒**：`quick_select_label_boxes()` 是**绘制观测点**而非命中盒（不吃指针）；每帧 `on_paint` 先清空，只回填本帧真的画出的候选，故「装不下/滚出可见窗就不在里面」与画面同源。
- **退模次序**：`Escape` 与 `Backspace` 排在修饰位判定之前（模式态这两个键不区分修饰）；字母键只在无可按住修饰位时折小写，`Shift+A` 走「其它键」退模。指针按下排在右键菜单的外点判定之前，故模式期的第一击只退模、不会顺带开菜单或起选区。
- **重开**：模式已开时再次触发不是「关闭」而是按当前视口重扫并重置前缀；无候选仍是 no-op。
- **验收读数**：`utest_quick_select` 12 案、`itest_quick_select` 8 案；`ctest --preset linux -E etest_` **110/110**、`borealis_test_runner` **1372/1372**（基线 108／1352）。四支变异各有指名红案：URL 尾部修剪、裸相对两斜杠闸、候选上限少一格、字母键吞位（后者红两案）。
- **仍未验证**：真机键位（`Ctrl+Shift+Space` 与 IME 的冲突）、命令闭包与焦点 pane 的装配跳（`src/main.cpp` 不编入 runner，裁决 7.83）、Win32／MSVC 编译与手感。
